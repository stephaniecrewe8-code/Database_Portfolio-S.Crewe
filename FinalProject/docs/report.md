# Final project report

Maximum five pages. Keep this exact six-part structure and replace prompts with actual project evidence.

## 1. Story and stakeholders (~½ page)
Name the real person, their pain, the place and the data that answers their question. Explain why it matters.

## 2. Schema and data model (~1 page)
Include one ER diagram, essential CREATE TABLE statements, enforced relationships, normalization level and reason.

## 3. Ingestion and pipeline (~¾ page)
Name the real data source, show the reproducible ingestion flow and explain how reruns stay idempotent.

## 4. Queries, indexes and evidence (~1¼ pages)
Show the headline query, EXPLAIN QUERY PLAN before and after the index, timings, and one negative or surprising result.

## 5. Security, integrity and evaluation (~1 page)
Show parameterization proof, malicious-input test, constraint/trigger/generated-column rule, measured evaluation numbers and one honest limitation.

## 6. Project Team and contributions (~½ page)
One line per member: name, owned component and evidence of their individual contribution.
