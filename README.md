## Run the reproducible exercises

The repository uses `uv`. From the repository root, run each module’s commands in its README. The Module 5 and 6 scripts create local databases and analytical files; these generated outputs are ignored by Git and should not be committed.

Reusable Module 5–6 scripts and project starter documents were imported from [Michael’s portfolio](https://github.com/MichaelKonsduAmpadu/michael-sql.portfolio) with attribution in the relevant module READMEs. Personal reflections, group decisions, measurements, peer-review results, and project evidence are not copied or invented.

## Evidence integrity

Benchmark timings, storage measurements, server observations, stakeholder feedback, team decisions, peer-review findings, and rehearsal outcomes must come from actual runs or activities. Replace the marked prompts in the evidence documents only after you have that evidence. Do not commit database files, Parquet files, credentials, or personal data.
