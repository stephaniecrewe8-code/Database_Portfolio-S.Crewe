Reflection on Module 2

I learned that creating tables is only one part of designing a database. I also need to think about how the information connects and what rules will keep it reliable. Building the
maintenance database and drawing its ER diagram helped me understand how machines, parts, and maintenance jobs relate. I found the diagram and integrity checks confusing at first, 
especially when the Mermaid preview did not appear. Working through the formatting helped me see that small details can affect how documentation displays. I still want more practice 
deciding which rules belong in the Python model and which should be enforced by the database.
